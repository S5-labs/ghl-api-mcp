# Template Library

The **Template Library** is integrated with the Marketplace, allowing agencies to **discover, preview, and install templates**, including paid ones.

If you want to **sell a template**, the process begins in the Template Library and continues in the **Seller Portal** (the developer/marketplace listing interface). The listing is created using details pre-filled from the selected template.

---

## Seller Portal: Account Setup, Listing, and Review

To list a template for sale:

1. Go to **My Templates** in the Template Library
1. Complete all required template details and publish it (if not already done)
1. Click the **three-dot menu (⋮)** on the template preview
1. Select **Sell on Marketplace**

### Developer Account

If you don’t already have a developer account, one will be **automatically created** during the seller flow. You can also choose to sign up manually.

### Completing Your Listing

Once the template-backed app is created, complete the listing in the following order:

1. **Basic Information** *(required)*
1. **Support Information** *(required)*
1. **Pricing** *(optional, only for paid templates)*
1. **Publish** the app after completing all required sections

### Scope of Template Marketplace Apps

Template Marketplace listings use a **streamlined app profile** designed specifically for template distribution. To keep onboarding simple:

- **OAuth and install-token capabilities are not supported** for this app type

### Review Process

All public listings go through a **manual review process**, with a target SLA of **10 working days**.

---

## Updating a Listed Template

### Minor Updates

For incremental changes to the **same listing**:

- Refresh the original template from the Template Library
- Add **release notes** (visible to agencies) describing the changes

This will automatically resubmit the app for review. Once approved:

- **New installations** will use the updated version
- **Existing installations** will remain unchanged

### Major Updates

If the changes are significant:

1. Withdraw the app from review in the Developer Portal
1. Make the necessary updates
1. Complete the listing steps again
1. Resubmit for a new review cycle

## End-User Experience (Overview)

For a detailed walkthrough, refer to the<br> [Template Library Marketplace Integration](https://help.leadconnectorhq.com/support/solutions/articles/155000007748-template-library-marketplace-integration) help article.

### Browsing Templates

- Navigate to **Template Library → Marketplace** (Agency View)
- Templates are also available via **App Marketplace → Templates**

### Discovering Templates

Users can find templates through:

- Search
- Categories
- Tags
- Template type
- Other catalog filters

### Installing Templates

1. Open a template
1. Click **Preview**
1. Click **Install**
1. If paid, complete the payment flow

After installation, the template appears under **My Templates** and can be used in the appropriate builder.

### Selling Templates

1. Open a template
1. Click **Preview**
1. Click **⋮ (three dots)** → **Sell on Marketplace**

This redirects to the **Seller Portal**, where template details are pre-filled. The process also includes **automatic developer profile creation** if needed.

### Pricing Model (Buyers)

- Templates are sold as **one-time purchases**
- There are **no recurring charges** for templates

---

## Supported Template Types

Only the following template types can be distributed via the Marketplace:

- **Forms**
- **Funnels**
- **Email Templates**
- **Websites**

Other template types are not currently supported.
