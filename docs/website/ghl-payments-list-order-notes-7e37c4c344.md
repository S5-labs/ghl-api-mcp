# List Order Notes

**Endpoint:** `GET /payments/orders/:orderId/notes`

List all notes of an order

## Request

**Version**

string

required

API Version

Available options

`v3`

**orderId**

string

required

ID of the order that needs to be returned

**altId**

string

required

Location Id or Agency Id

**altType**

string

required

Available options

`location`

Successful response
