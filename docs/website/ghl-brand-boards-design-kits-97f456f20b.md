# Design Kits

Documentation for Brand Boards API

## 📄️List Design Kits

Get list of design kits for a location

## 📄️Create Design Kit

Create a design kit for a location

## 📄️Get Design Kit

Get a design kit by ID

## 📄️Update Design Kit

Update a design kit by ID

## 📄️Delete Design Kit

Delete a design kit by ID

## 📄️Set Default Design Kit

Set a design kit as the default for a location. The previous default will be unset.
