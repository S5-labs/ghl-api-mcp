# Assessment

API Service for Courses and Memberships

## 📄️List Assessments

List assessment submissions for a course. Requires a Location token with courses.readonly. Send Version: v3.

## 📄️Get Assessment

Get one assessment submission. Requires a Location token with courses.readonly. Send Version: v3.

## 📄️Review Assessment

Review an assessment submission. Requires a Location token with courses.write. Send Version: v3. Location tokens are not a staff reviewer.
