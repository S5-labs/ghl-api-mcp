# Faqs

Documentation for Knowledge Base API

## 📄️Get all FAQs by knowledge base with pagination support

Retrieves Q&A entries for a knowledge base, with cursor or offset pagination and optional question search.

## 📄️Create a new FAQ inside knowledge base

Creates a new question-and-answer entry in a knowledge base.

## 📄️Update an existing knowledge base FAQ

Updates the question and/or answer of an existing FAQ.

## 📄️Delete an existing knowledge base FAQ

Permanently deletes one FAQ from a knowledge base.
